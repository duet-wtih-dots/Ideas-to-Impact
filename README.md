# Ideas to Impact

Ideas to Impact is a hands-on, notebook-based course for learning how to work with Claude and apply prompt engineering to practical problems. Lessons are organized into numbered day folders and combine explanations with runnable Python examples using the Anthropic API.

## Getting Started

1. Clone this repository and open a lesson notebook, starting with [Day 1](Day-1/00_Tutorial_How-To.ipynb).
2. Install the Anthropic Python SDK:

   ```bash
   pip install anthropic
   ```

3. Configure an Anthropic API key as `ANTHROPIC_API_KEY` in your notebook environment. The Day 1 tutorial uses Google Colab's Secrets (`userdata`) to retrieve it.
4. Run the notebook cells from top to bottom, then continue through the numbered lessons.

An Anthropic API key is required to run the interactive examples. The Day 1 tutorial also links to a static answer key for readers who do not have a key.
